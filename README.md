# Datelar - Web Oficial & Landing Page

Landing page oficial de **Datelar**: soluciones de hardware IoT, telemetría vehicular avanzada (**SENTNLDRIVE** en fase beta), gestión de accesos QR (**Datelar Access**) y el laboratorio de software e innovación **Datelar Labs**.

## Ecosistema Datelar

* **SENTNLDRIVE [FASE BETA]**: Telemetría vehicular de alta sensibilidad, monitoreo de flotas en tiempo real, corte remoto de motor y roadmap CAN bus.
* **Datelar Access**: Producto de **Datelar Labs** para control inteligente de aforo y boletería mediante códigos QR dinámicos e infalsificables con validación offline.
* **Hardware & IoT a Medida**: Diseño electrónico de PCB, sensores embebidos industriales y conectividad (4G LTE, NB-IoT, LoRaWAN).
* **Datelar Labs**: División de Datelar Labs creada por **Gerardo Gonza**, hogar de plataformas como **Datelar Access**, aplicaciones como **Music Muv**, utilidades para ingenieros de telecomunicaciones y scripts embebidos.

## Despliegue en Vercel

Este proyecto está configurado con arquitectura estándar de Next.js para despliegue directo en **Vercel**:

1. Sube este repositorio a GitHub / GitLab / Bitbucket.
2. En [Vercel](https://vercel.com), selecciona **Add New Project** e importa el repositorio `DATELAR`.
3. Vercel detectará automáticamente Next.js. Haz clic en **Deploy**.
4. ¡Tu landing page estará en línea en segundos!

## Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
